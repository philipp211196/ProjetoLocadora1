AUTOLOC - SISTEMA DE LOCADORA (RECONSTRUCAO)
=============================================

Projeto Windows Forms (.NET 8) com MySQL.

REQUISITOS
----------
- Windows 10 ou 11;
- Visual Studio 2022 com desenvolvimento desktop .NET;
- .NET 8 SDK;
- MySQL Server;
- Internet para restaurar MySqlConnector 2.4.0 na primeira compilacao.

COMO ABRIR
----------
1. Clone ou baixe este repositorio.
2. Abra ProjetoLocadora1.csproj no Visual Studio 2022.
3. Configure a conexao do MySQL antes de executar.
4. Espere a restauracao dos pacotes NuGet.
5. Pressione F5.

CONEXAO MYSQL (VARIAVEIS DE AMBIENTE)
-------------------------------------
LOCADORA_MYSQL_SERVER = 127.0.0.1
LOCADORA_MYSQL_PORT = 3306
LOCADORA_MYSQL_DATABASE = locadora_veiculos
LOCADORA_MYSQL_USER = root
LOCADORA_MYSQL_PASSWORD = (sua senha local)

No Windows: menu Iniciar > Editar as variaveis de ambiente da sua
conta > Novo. Adicione o nome e o valor de cada variavel desejada.
Feche e reabra o Visual Studio apos as alteracoes.

O programa tenta criar o banco e as tabelas se nao existirem:
Clientes, Veiculos e Locacoes. O usuario precisa das permissoes
correspondentes. O programa nao remove registros existentes.
Se o MySQL estiver sem senha apenas no seu computador de estudo,
a variavel de senha pode ficar vazia.

INTERFACE RECONSTRUIDA
----------------------
- Aba Clientes: cadastro e listagem.
- Aba Veiculos: cadastro e listagem.
- Aba Locacoes: registro, consulta e cancelamento.
- Tema escuro e interface construida diretamente em Forms/FormPrincipal.cs.

INFORMACOES TECNICAS
--------------------
- Program.cs chama BancoDados.InicializarBanco() e abre FormPrincipal.
- Data/BancoDados.cs implementa acesso a dados com SQL parametrizado.
- A tabela Veiculos tem placa unica.
- Locacoes ativas para o mesmo veiculo nao podem sobrepor datas.
- Valor total da locacao = quantidade inclusiva de dias * diaria.
- Esta versao NAO contem arquivos .Designer.cs; as telas sao geradas
  pelo codigo de FormPrincipal.cs.

SEGURANCA E LIMITACOES
----------------------
- Nao publique senhas em arquivos, mensagens ou commits.
- Fora de estudos, crie usuario MySQL com permissoes limitadas.
- CPF, email e telefone possuem validacoes basicas/incompletas.
- Projeto nao esta homologado para uso comercial.
- Compilacao e execucao ainda precisam ser verificadas no Windows.

Se surgir erro na inicializacao, confira a mensagem na janela,
as credenciais MySQL e as permissoes do usuario.
